AML DATA ANALYSIS
OVERVIEW -Analyzed financial transaction to identify pattern associated with potential money laundering activities using SQL , Python, PowerBI.
ANALYSIS
Cleaned and explored transaction data using python.
Used SQL to analyze transaction amount, payment type, curriencies,bank ,locations, laundering activities.
created an interactive power BI dashboard to visualize transactions and laundering patterns.
KEY FIELDS
Transaction Amount,Time, Date, Payment type, Sender/Reciever bank , Bank location, Is_laundering and laundering type.
OUTCOME
The project demonstrates the use of Python, SQL, PowerBI to analyze financial transaction data and present meaningful insight throught interactive dashboard.
